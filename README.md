<h3>Jetpack Compose → Ejercicios de componentes</h3>

<h2>Ejercicios de componentes</h2>

<p>1. Crea un composable de ventana de login. Carga una imagen que haga de logo de la aplicación (puedes usar el logo de cualquier página o crear el tuyo propio):</p>

<ul>
  <li><b>a.</b> Nombre de usuario</li>
  <li><b>b.</b> Password</li>
  <li><b>c.</b> Botón de aceptar</li>
  <li><b>d.</b> Botón de limpiar</li>
  <li><b>e.</b> Botón de Registrarse</li>
</ul>

---

<p>2. Crea un composable de ventana de registro. Haz que el formulario sea bonito usando iconos:</p>

<ul>
  <li><b>a.</b> Nombre de usuario</li>
  <li><b>b.</b> Password</li>
  <li><b>c.</b> Repite password</li>
  <li><b>d.</b> Nombre y apellidos: dos TextField en la misma fila, apellidos debe ocupar el doble de ancho que nombre</li>
  <li><b>e.</b> Email</li>
  <li><b>f.</b> Bio: TextField multilínea que se expande a todo el alto disponible</li>
  <li><b>g.</b> Botón de aceptar</li>
  <li><b>h.</b> Botón de cancelar</li>
</ul>
